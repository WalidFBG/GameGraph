    A game, one decision at a time

    The NBA is modelled as a graph of decisions. Each box is a node: a question answered by a fitted model (who shoots, does it go in, how long did the action take). After each answer the rules update the game and say which node comes next. Grey dashed boxes are rules, not decisions.

    Play sends the ball through the graph; Step moves one decision. In Auto every answer is drawn at random with the shares a simulation of a real game produced; in You decide the game stops at each node for you to answer, or to let it draw.

    Click any node to see what it asks, how often each answer comes up, what it reads and where it leads. The Play-by-play tab lists every decision, the Court tab the players on court, fouls and timeouts.

    The auto draws use each node's average outcome shares over 2,000 simulations of one game, not the fitted models' answers for the situation, so a game here is plausible, not a forecast.
